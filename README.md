# ChessMind

ChessMind is a modern online chess application built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Features

- **Online Multiplayer**: Play with friends or match with players.
- **Play Against AI**: Challenge Stockfish at various difficulty levels.
- **Interactive Learning**: Puzzles, lessons, and practice modes.
- **Rating & History**: Track your Elo rating progression and analyze past games.

## Development

Prefer working locally? You need Node.js and npm.

```sh
git clone <this-repository-url>
cd chess-project
npm install
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Stockfish AI
- Firebase / Firestore
